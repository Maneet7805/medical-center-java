## 🎯 Overview

**Medical Center Java System** is a feature-rich desktop application designed to streamline the management of patient records, appointments, and prescriptions in a medical center. Built with **Java Swing and AWT**, this application demonstrates robust **Object-Oriented Programming (OOP)** principles while providing an intuitive graphical user interface for healthcare staff.

### ✨ Why This Project?
- ✅ **Learn OOP concepts** through practical implementation
- ✅ **Understand GUI development** with Java Swing
- ✅ **Build a real-world** medical management system
- ✅ **Practice clean code** and MVC architecture
